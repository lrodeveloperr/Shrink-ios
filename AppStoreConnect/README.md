# App Store Connect release pack

This folder contains the finalized non-media metadata for Shrinkflation Price Scanner 1.0 (8). It does not contain screenshots, previews, or other media. Nothing in this folder uploads a build, selects a build, submits the app, or changes App Store Connect.

## Locale routing

- English (U.S.) uses `en-US`.
- App Store Connect does not offer a Puerto Rico Spanish metadata locale. The `es-MX` folder is the delivery container; its wording is native Puerto Rico Spanish and was reviewed independently by a fully bilingual expert.

## Release state

The non-media listing copy is final. The policy sources are published to the routes used by the app; an automated public-response check was blocked by the site edge and remains a human verification gate. The overall release remains blocked until the production ad configuration, privacy declarations, current reviewer contact, media, signed archive, and device/IAP tests are complete.

## Files

- `listing-en-US.md` and `listing-es-MX-pr.md`: final public metadata
- `iap-localizations.md`: non-consumable display names and descriptions
- `privacy-answer-pack.md`: code-grounded App Privacy preparation
- `review-notes.md`: App Review navigation and limitations
- `listing-manifest.json`: machine-checkable evidence and blockers
- `TestFlight/`: prepared beta metadata; not wired or uploaded
